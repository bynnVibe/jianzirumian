# 噪声规则清单与扩展（L3 参考）

本文件是 `article-content-clean` 的执行层参考，仅在需要完整噪声正则或扩展规则时按需加载。
对应实现：`app/services/article_clean.py`。

## 1. 内置整行噪声正则（`_NOISE_RES`，命中即删整行）

| 类别 | 正则（简化） | 命中示例 |
| --- | --- | --- |
| 页码 | `^第?\s*\d{1,4}\s*页?(…共?\d{1,4}页?)?$` | `第 3 页` / `3 / 12 页` / `第1页 共2页` |
| 页码（破折号） | `^[-—–]\s*\d{1,4}\s*[-—–]$` | `- 5 -` |
| 版权/转载 | `版权所有｜转载或(转载必究｜请注明)｜注明出处｜All Rights Reserved｜Copyright` | `版权所有，转载请注明出处` |
| 关注/分享引导 | `扫码关注｜长按二维码｜点击上方蓝字｜点击关注｜关注我们｜关注公众号｜阅读原文｜本文源自｜来源[:：]?\s*$` | `扫码关注本公众号` |
| 互动引导 | `^(点赞｜在看｜分享｜收藏｜转发｜一键三连｜打赏｜赞赏｜喜欢此内容).{0,8}$` | `点赞在看` |
| 署名行 | `^(编辑｜责编｜审核｜校对｜整理｜摄影｜文｜图｜来源｜作者)[:：]` | `作者：张三` |
| 上下篇/相关阅读 | `上一篇｜下一篇｜上一页｜下一页｜返回首页｜相关阅读｜推荐阅读｜延伸阅读｜猜你喜欢｜往期回顾` | `上一篇：如何测血压` |
| 纯 URL 行 | `^https?://\S+$` | `https://example.com/a` |
| 广告/推广 | `^(广告｜推广｜赞助｜点击领取｜免费领取｜扫码领取｜限时优惠)` | `广告：限时优惠` |

另有**纯符号行**兜底：`_SYMBOL_ONLY_RE = ^[\W_]+$` 且长度 ≤40 字（如 `●●●`、`---`、`***`），
避免误删正文短句。

## 2. 行内角标（`_FOOTNOTE_RE`，只删角标本身）

`[\[【]\d{1,2}(?:[,，、]\d{1,2})*[\]】]` —— 命中 `[1]`、`【2】`、`[1,2]`、`[3、4]`。
删除后若 `collapse_spaces` 开启则再折叠一次空格；若整行因此变空则删行。

## 3. 空格与空行

- `_SPACE_RE = [ \t\u3000\u00a0]+`：半角空格/制表/全角空格/不换行空格 → 折叠为单个空格并去首尾。
- 连续空行压缩为一个（`collapse_blank_lines`）；整行被删后若上一输出行已是空行，继续参与压缩
  （`_mark_removed`），避免删行后留下多余空行。

## 4. 扩展规则（借鉴 text-cleaner，走 `extra_line_patterns`）

`text-cleaner` 清理的「技术噪声」（时间戳、残留 HTML 标签、技术注释、emoji）在本项目中
**默认不内置**，因为链接正文经 `url_skills.clean_article`（markdownify）后一般已无 HTML 标签，
激进删除易误伤正文。确有需求时，用 `extra_line_patterns` **按需追加整行删除正则**（≤10 条，每条 ≤120 字）：

```json
{
  "remove_footnote_markers": true,
  "remove_noise_lines": true,
  "collapse_spaces": true,
  "collapse_blank_lines": true,
  "extra_line_patterns": [
    "^\\d{4}-\\d{2}-\\d{2}\\s+\\d{2}:\\d{2}",
    "^\\[?\\d{1,2}:\\d{2}(:\\d{2})?\\]?$",
    "^(免责声明|本文特约|本站原创)\\s*[:：]?",
    "^[\\U0001F300-\\U0001FAFF\\u2600-\\u27BF]+\\s*$"
  ]
}
```

- 时间戳行：`^\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}`、纯时间码 `^\[?\d{1,2}:\d{2}(:\d{2})?\]?$`。
- 栏目声明行：`^(免责声明|本文特约|本站原创)\s*[:：]?`。
- 纯 emoji 行：`^[\U0001F300-\U0001FAFF\u2600-\u27BF]+\s*$`（Python `re` 用 `\U0001F300` 8 位转义表示 astral 平面 emoji）。

> 注意：`extra_line_patterns` 是**整行删除**语义（`re.search` 命中即删该行），
> 不适合做「行内替换」式清理（如把行中 emoji 抠掉但保留句子）。行内清理属改写，超出本技能
> 「只减不增、保句完整」的边界，应交给 LLM 润色（polish-ocr）处理。

## 5. 容错

`_compile_extra_patterns` 对非法正则**跳过并告警**（`logger.warning`），不影响其余规则执行；
校验层 `_validate_polish_policy` 在落库前已拦截非法正则（返回错误，不入库）。
