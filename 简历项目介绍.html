壹门禁分层防死锁

结论："评测通过才可用"门禁只加目录层，执行层 resolve 保持开放。取舍：评测自调用需解析未过评工具，门禁下沉会形成死锁。被否：resolve 统一加门禁、三处各自实现判定（多写点漂移）。

贰双通道记忆保显式指令

结论：确定性规则层旁路 + LLM 层并行，"记住/忘记"类指令不依赖模型必定落库。取舍：模型判空不得整轮静默 return；互斥窗口只拦 LLM 层。被否：单 LLM 通道（故障即丢指令）。

叁真实 usage 校准分摊

结论：6 段 Token 估算占比以 LLM 真实 prompt_tokens 校准落库，构成口径与成本口径同维可比。取舍：无真实 usage 时 scale=1 退化估算，保证降级一致。被否：纯估算入库（与账单口径漂移）。

肆SSRF 规范化层拦截

结论：URL 抓取在规范化层拦主机名，DNS 解析仅作第二道防线。取舍：先拦后解析，避免解析窗口被利用。被否：仅靠 DNS 解析后校验（存在盲区）。

效果类数字（缓存命中率、首 token 延迟、单请求 token 环比）请从可观测性面板取真实测量值补入第 4、5 条，比虚构数字更扛追问。
